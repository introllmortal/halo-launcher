====================================================================
Инструкция по обновлению и привязке сборки Create Clockwork Empire
====================================================================

Этот патч переключает сборку на автоматические обновления через GitHub 
в Halo Launcher и обновляет название с иконкой.

КАК ПРИМЕНИТЬ ПАТЧ:
1. Полностью закройте игру Minecraft и Halo Launcher.
2. Скопируйте файлы патча (patch_instance.bat, patch_instance.ps1, clockwork_empire.jpg)
   НЕПОСРЕДСТВЕННО В ПАПКУ ВАШЕЙ СБОРКИ:
   (Туда, где находится файл instance.cfg или папка .minecraft).
   Вне папки инстанса патчер работать не будет!
3. Запустите файл patch_instance.bat прямо из этой папки.
4. Дождитесь зеленого сообщения "[OK] ПАТЧ УСПЕШНО ПРИМЕНЕН!".

КАК ОБНОВЛЯТЬ СБОРКУ В ДАЛЬНЕЙШЕМ:
1. Запустите Halo Launcher.
2. Нажмите правой кнопкой мыши по сборке -> "Редактировать" (Edit).
3. Перейдите на вкладку обновлений сборки GitHub (с иконкой шестеренки/обновления).
4. Нажмите кнопку "Обновить сборку" (Update Pack).
Лаунчер сам автоматически загрузит новые моды, конфиги и скрипты!
